Show the cstman quick-reference card.

| Command | What |
|---|---|
| `/cstman` | CSTMAN voice, default |
| `/ultracst` | Maximum compression |
| `/megacst` | Classical Chinese (文言文) |
| `/cstman off` | Deactivate |
| `/cstman-commit` | Terse commit message |
| `/cstman-review` | One-line review findings |
| `/cstman-compress <file>` | Compress a Markdown file |
| `/cstman-stats` | Lifetime token-savings |

Natural language also works: "turn on cstman", "stop cstman", "normal mode".

Code, commits, security warnings: cstman drops out automatically.
